# Self-organizing Kohonen map

## Порівняння решіток SOM

Відкрийте **Tools → Порівняння решіток SOM**. Імпортуйте JSON-масив об’єктів,
позначте числові ознаки та виберіть колонку ID. ID виключається з навчання й має
бути унікальним та непорожнім. Без такої колонки використовується `row:1`, `row:2`, …
за порядком вихідних записів. Пропуски й нечислові значення не підміняються нулями:
для навчання доступні лише колонки зі скінченними числами в усіх рядках.

Виберіть нормалізацію (без неї, min–max або z-score), спільні розміри карти,
ітерації, швидкість та радіус. Одна ітерація — повний прохід вибірки. Метрика
евклідова, сусідство гаусове в межах поточного радіуса. Квадратна решітка використовує
евклідову відстань між вузлами, гексагональна — відстань у кубічних координатах.
Обидві карти мають `ширина × висота` нейронів, без замикання країв.

Типово запускаються 10 пар (20 навчань), k-means має `k = 4`, seed 42,
максимум 100 ітерацій та одну ініціалізацію. Автоматичний режим генерує унікальні
seed із базового seed. У ручному режимі вставте список через пробіл, кому, крапку
з комою або новий рядок; довжина списку визначає кількість пар. Повторення — помилка.
Фактичні seed відображаються до натискання **Запустити серію**; seed 0 тут є
звичайним відтворюваним seed.

Нормалізація виконується один раз для всієї серії; константні ознаки після
min–max/z-score дорівнюють нулю. Для кожного seed початкові ваги створюються
наявним `Map.Initialize`, копіюються окремо для обох карт і перевіряються за SHA-256.
Нові серії типово використовують **Порядок рядків → Як у SOMWizard (порядок файлу)**.
Для відтворення одиночної карти вкажіть її фактичний seed у власному списку,
виберіть ті самі числові ознаки в тому самому порядку, вимкніть нормалізацію та
повторіть розміри, швидкість, ітерації й радіус (для 15×10 він дорівнює 7).
Для перевірки виділіть нейрон у тих самих координатах на тій самій решітці.
Стовпець **Середня вага нейронів** відповідає **Average values** у головному вікні.
Режим **Перемішати один раз за seed** використовує Fisher–Yates. В обох режимах
карти пари отримують однаковий порядок на кожній ітерації. Старі файли
`.somcmp` відкриваються з перемішуванням, яке застосовувалося під час їх навчання.
Після зміни порядку натисніть **Запустити серію**. На вкладці **Карти** біля seed
видно режим завершеного навчання та перші п’ять номерів рядків, якщо їх збережено.
У таблиці **Результати за seed** і відповідному CSV є SHA-256 повного порядку рядків.

Після SOM наявний k-means кластеризує всі вагові вектори нейронів; абонент отримує
кластер свого BMU. Силует обчислюється точно для всіх абонентів у спільному
нормалізованому просторі (час O(N²), без матриці всіх відстаней). Для одиночного
елемента кластера силует 0; якщо зайнятих кластерів менше 2 або стільки ж, скільки
абонентів, результат — «н/д» із причиною. ARI зіставляє записи за ID та не залежить
від номерів кластерів. Стабільність використовує всі унікальні пари завершених
запусків відповідної решітки. Профілі містять середні у вихідних одиницях; порожні
кластери мають кількість 0 та середні «н/д». Для вибраного seed алгоритм Угорського
зіставлення максимізує сумарний перетин абонентів двох карт.

**Скасувати** зберігає всі повністю розраховані запуски. Таблиця позначає неповні
пари; парні різниці й міжрешітковий ARI включають лише повні пари. Лічильник
навчань SOM може перевищувати кількість готових запусків, якщо скасування сталося
на етапі k-means або метрик. Повторний запуск з тими самими параметрами створює
нову серію; перед ним можна експортувати попередню.

**Експорт у CSV** пропонує вибрати розташування нової папки з часовою позначкою:

- `summary.csv` — кількості та медіана/мінімум/максимум показників;
- `metrics_by_seed.csv` — силуети, парна різниця, ARI та статуси;
- `pairwise_ari.csv` — міжрешіткові й міжseed порівняння;
- `cluster_profiles.csv` — профілі всіх кластерів усіх завершених запусків;
- `matched_profiles.csv` — зіставлені профілі всіх повних пар;
- `experiment.json` — фактичні seed, набір даних, SHA-256 вибраних даних та ID,
  ознаки, усі параметри, зсуви/масштаби нормалізації, контрольні суми початкових
  ваг і порядку, час та стан серії.

Окрема кнопка **Експорт призначень абонентів** створює `assignments.csv`
(`seed,lattice,subscriber_id,bmu_x,bmu_y,cluster`) і `experiment.json` у новій папці.
CSV: UTF-8 з BOM, кома як роздільник, крапка в числах, екрановані лапки й переноси.
Частки задані від 0 до 1; індекси BMU й кластери починаються з 0. Для відтворення
збережіть вихідний JSON та його порядок рядків разом з експортом.

### Перегляд карт і збереження результатів

На вкладці **Карти** виберіть seed. Дві решітки показують усі нейрони, а спільний
колір позначає кластери, зіставлені за перетином абонентів. Число у клітині —
кількість абонентів із цим BMU. Клацання додає або прибирає клітину, протягування
поширює цю дію на сусідні клітини. Таблиця під картами обчислює для поточного
seed середню вагу виділених нейронів у вихідних одиницях і середні значення
унікальних абонентів з обох виділених ділянок. Порожній нейрон враховується
у середній вазі. Той самий абонент на двох картах враховується один раз.

У режимі **Карти ознак** кожен seed має власну секцію. Ліворуч стоять поруч карти
ознак гексагональної решітки цього seed, праворуч — карти ознак квадратної.
Як і в головному вікні, карти переносяться на наступний рядок, коли бракує ширини.
Меню **Показати ознаки** вмикає й вимикає ознаки в обох блоках.
Позначте **Усі seed**, щоб бачити секції за порядком запусків. Шкала кожної
ознаки спільна для всіх завершених карт, а її межі підписані у вихідних одиницях.
Виділення нейронів спільне з режимом кластерів. **Зберегти PNG…** створює
зображення всіх увімкнених пар із підписами й легендами, включно з рядками
за межами вікна. Файл результату зберігає вибір видимих ознак і режим перегляду.

У заголовку кожної решітки, зокрема в PNG, відображається тривалість циклу
навчання SOM для її seed. Вимір починається перед першою ітерацією і закінчується
після останньої, до k-means. Значення в секундах зберігаються в `.somcmp`,
`metrics_by_seed.csv` і `experiment.json`. Для старих результатів без виміру
час позначається «н/д».

**Зберегти результат…** записує серію у файл `.somcmp`, включно з вагами,
призначеннями, вихідними значеннями вибраних ознак, показниками й виділенням
для кожного seed. **Відкрити результат…** відновлює карти, таблиці та налаштування
із цього файлу навіть без вихідного JSON. Можна зберігати й перервані серії.

### Перевірки модуля

У Developer PowerShell для Visual Studio:

```powershell
msbuild Tests/Comparison.Tests.csproj /t:Build /p:Configuration=Debug /p:SignManifests=false /p:GenerateManifests=false
./Tests/bin/Comparison.Tests.exe
```

Тестовий виконуваний файл не потребує зовнішнього тестового фреймворку. Він перевіряє
два seed / чотири навчання, початкові умови, призначення, повторний запуск,
скасування на всіх трьох етапах, незавершені пари, відомі значення ARI/силуету,
оптимальне зіставлення, нормалізацію, ID, збіг CSV із таблицями та завантаження
обох WPF-вікон. Тестові експорти містяться у `Tests/bin/test-export`.
